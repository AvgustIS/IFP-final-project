# Материалы для защиты

- **Отправить преподавателю:** [английская презентация, 12 слайдов](for_teacher/EasyShop_KZ_Defense_EN.pptx). Перед отправкой впиши ФИО на титульном слайде.
- **Оставить себе:** [заметки для выступления и демонстрации](for_me/DEFENSE_NOTES_RU.md). Здесь пояснения по каждому слайду, команды, ответы на вопросы и технические ограничения.

Полные исходные презентации и технические отчёты сохранены в docs. Копию для преподавателя можно заново создать командой `python tools/create_teacher_presentation.py` при установленном python-pptx.
