# Руководство пользователя

## Покупатель

1. Откройте `/catalog`. Поиск работает по названию без учёта регистра. Можно выбрать категорию, сортировку цены и наличие; Reset очищает фильтры.
2. Откройте карточку товара или нажмите Add to cart. Количество ограничено доступным остатком.
3. В `/cart` измените количество кнопками +/− или удалите позицию. Нулевое количество удаляет товар. Корзина сохраняется при обновлении и входе в той же вкладке.
4. Зарегистрируйтесь в `/register`: имя 2–120 символов, корректный email до 120 символов, пароль 8–128 символов. Войдите через `/login`.
5. Перейдите в `/checkout`, заполните имя, телефон и адрес. Cash on Delivery означает оплату при получении; Demo Card только имитирует способ оплаты. Данные банковской карты не запрашиваются.
6. Нажмите Place order один раз. Сервер проверит актуальные цены и остатки. При нехватке товара заказ не создаётся и склад не изменяется частично.
7. В `/orders` доступны только ваши заказы. Выйти можно кнопкой Logout.

## Администратор

Учётная запись создаётся при запуске с переменными окружения из README. Обычная регистрация всегда создаёт Customer.

- `/admin` — количество товаров, пользователей и заказов; сумма заказов без отменённых. Счётчик пользователей включает администратора.
- `/admin/categories` — добавление, изменение и удаление категорий. Категорию с товарами удалить нельзя.
- `/admin/products` — управление товарами. Цена от 1 до 99 999 999, максимум два знака после запятой; остаток от 0 до 1 000 000. Изображение: локальный путь `/images/...` или HTTPS URL.
- `/admin/orders` — Pending → Processing → Completed; Pending и Processing можно отменить. Отмена возвращает остатки один раз. Завершённый заказ отменить нельзя.
- Удаление товара сохраняет его название, цену и количество в уже оформленных заказах.

При сообщении о занятости базы повторите действие. При истёкшем токене формы обновите страницу. Для восстановления после внутренней ошибки перейдите на главную; серверный журнал содержит детали для разработчика.
